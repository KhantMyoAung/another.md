About this build

Five scientists: two you have heard of and three who are routinely left out of the story. Each quest node is a documented contribution with a date, and each character sheet ends with the sources it was written from.

The portraits are not photographs and not AI generations — they are drawn in code from a single shared rig, so the five read as one set. Nobody knows what Ibn al-Haytham looked like; that one is an acknowledged invention.

The stat lines are an editorial flourish. Everything else is meant to survive checking.

Three.js · generated SVG · Web Audio · no external requests.
